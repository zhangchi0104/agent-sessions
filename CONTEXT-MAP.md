# Context Map

This repo hosts more than one bounded context. Each has its own glossary.

- **Agent Sessions** — tracking live coding-agent sessions and their status across Claude Code / Codex. Glossary: [`apps/agent-sessions-tui/CONTEXT.md`](apps/agent-sessions-tui/CONTEXT.md). Spans `apps/agent-sessions-tui` (viewer), `apps/agent-sessions-cli` (hook handler), `packages/actions`, `packages/database`.
- **TokenStats** — macOS status-bar app showing a coding agent's usage allowance. Glossary: [`apps/TokenStats/CONTEXT.md`](apps/TokenStats/CONTEXT.md).
