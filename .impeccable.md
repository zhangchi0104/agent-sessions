# Impeccable Design Context

> Synthesized from CONTEXT.md, PRD notes in code comments, and ADRs (apps/TokenStats).
> The TokenStats macOS menu-bar app is the repository's only UI surface.

## Design Context

### Users
Software developers who run AI coding agents (Claude Code first, Codex second) all
day and keep one eye on their usage allowance. They interact in 2–5 second glances:
click the menu-bar item mid-task, read, dismiss. They are on macOS, usually dark
mode, often with many monitors and a full menu bar. Power users; zero tolerance for
wrong numbers, high tolerance for density.

### Use Cases
- "How much of my 5-hour Usage Window is left, and when does it reset?" (primary, hourly)
- "Where did my tokens go — which agent, which model, fresh context or cache?"
  (the Tokens tab's breakdown table, over a range of up to 30 days)
- Account management (sign in/out) — rare, lives in Settings, not the popover.

### Brand Personality
Quiet, precise, trustworthy. A native macOS utility in the menu-bar tradition
(iStat Menus, Stats): system-consistent, data-forward, no web-app chrome. The app's
core promise (from the PRD): it never shows a wrong number — only a fresh one or a
disclosed-stale one. The UI should feel like part of macOS, not a brand.

### Aesthetic Direction
- Native SwiftUI with system materials; Liquid Glass on macOS 26 where it earns
  its place, not as decoration.
- SF Pro (system) typography is CORRECT here — native apps should not ship custom
  display fonts. Rounded-design monospaced digits are the app's number language.
- Color is state, not decoration: green/yellow/red thresholds for remaining
  allowance, orange for needs-attention, accent tint for selection. Monochrome
  menu-bar label (PRD requirement).
- Adapts to light/dark via system; no forced theme.

### Design Principles
1. Glanceable first: the primary reading must land in under a second.
2. Never wrong: stale data is always disclosed as stale, never dressed as fresh.
3. System-native: materials, spacing, and controls follow macOS HIG; the app
   should be indistinguishable from a first-party utility in craft.
4. Numbers are the interface: typography and alignment of figures carry the
   hierarchy; chrome stays quiet.
5. Color only for state — if everything is colored, nothing is.
